# Branch Offices

<!-- Sources: patches/snapshots/4.4.6.md (audit: patches/audits/4.4.6.md); patches/4.5.md (stable 4.5 release notes, Dev Diary #433) -->

- **Branch Offices:** Branch Offices use Trade, rather than Energy, for establishment. Their value and availability still depend on corporate rules and the target empire. {since: 4.4.6, until: 4.5}

- **Branch Offices:** Building a Branch Office costs 75 Influence plus a distance penalty of 5 Influence per jump. {since: 4.5}
