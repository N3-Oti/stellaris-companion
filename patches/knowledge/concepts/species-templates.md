# Species Templates

<!-- Sources: patches/snapshots/4.4.6.md (audit: patches/audits/4.4.6.md) -->

- **Default Species Templates:** One template can be selected as a species' Default Template. A sub-species set to Sub-Species Integration is automatically altered toward that default over time; other sub-species are not forced to integrate. {since: 4.4.6}
