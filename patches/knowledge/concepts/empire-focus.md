# Empire Focus

<!-- Sources: patches/snapshots/4.4.6.md (audit: patches/audits/4.4.6.md) -->

- **Empire Timeline:** The Situation Log includes an Empire Timeline that records major milestones. A milestone appearing there is campaign evidence; a general mechanic describing a milestone is not proof that it occurred. {since: 4.4.6}

- **Focus Categories:** Empire Focus uses Core tasks plus Conquest, Exploration, and Development categories. The selected primary focus changes which category tasks are more likely to be drawn; it does not by itself change the draw weights of ordinary technology cards. {since: 4.4.6}

- **Focus Tasks:** Focus cards provide short- and medium-term tasks. Completing a task advances the relevant category's progression and can grant its stated reward. {since: 4.4.6}

- **Guaranteed Research:** Focus progression unlocks permanent research options for technologies considered important to that category. This is a deliberate route to key technologies, not merely a modifier to random draw weights. {since: 4.4.6}

- **Refocusing:** A current task can be dismissed and replaced for a Unity cost when the interface permits it. Changing the primary Focus and dismissing one task are distinct actions. {since: 4.4.6}
